## 目标与范围

修复长览预览变形、底部缩略图原生拖拽冲突，提高左右键移动的连续性，并为放大、缩小加入与 `1:1` 一致的缓动。修改现有静态页面的视图控制、预览布局与输入事件；会话-10明确追加提交、GitHub Pages 发布及线上验证。

## 验收标准

1. 桌面与窄屏长览图片保持素材比例，横向浏览后点选仍定位正确。
2. 拖动底部导航不触发原生图片拖拽；视野框抓取不跳位，释放、取消后不再跟随。
3. 长按左右键由浏览器逐帧驱动，短按、反向、松键、失焦和视图边界行为正确。
4. 放大、缩小、`1:1` 使用相同缓动；连续点击累积目标比例，其他输入可接管动画。
5. 保持减少动态效果偏好、原图坐标、寻物、百科与存档正常。

## 当前有效结论

- 长览按图片固有比例显示，固定浏览高度，超宽内容横向滚动；定位基于图片实际边界。
- 导航明确管理单个指针和捕获生命周期，并禁用浏览器原生图片拖拽。
- 方向键按屏幕刷新逐帧计算速度；尺寸在视口变化时缓存，避免动画每帧测量布局和重建缩放文字。
- 缩放按钮复用原有 650 毫秒缓动，快速点击累积目标值，滚轮维持鼠标锚点。
- 操作接管后忽略旧按键的自动重复，避免再次启动已取消的连续移动。
- 原始 JPG、音频和部署配置不在本轮修改范围。
