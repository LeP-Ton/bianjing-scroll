# 入画 · 汴京寻物

在《清明上河图》中寻物，读一段宋人日常。

[在线游玩](https://lep-ton.github.io/bianjing-scroll/) · [GitHub 仓库](https://github.com/LeP-Ton/bianjing-scroll)

## 打开游戏

在本目录运行：

```sh
node server.mjs
```

再打开 http://localhost:4173。无需安装依赖，无需构建。

也可直接打开 `dist/index.html` 游玩，但音效加载需要 HTTP 环境，完整声音体验请使用本地服务或在线版本。

- 虹桥春市、汴河舟楫、城郭烟火三卷，共十四处真实点位。

- 十七条生活百科，涵盖服饰、饮食、交通、建筑、商业、器具与风物。

- 六首原创合成配乐、七种动作音效，以及独立音量、开关和选曲。
- 直接加载原始 JPG、原图像素 `1:1` 查看和原图下载。

进度仅保存在当前浏览器。文件打开与不同本地地址的存档各自独立。

## 配乐与音效

右上角声音按钮打开“听汴京”。点击“奏乐”开始配乐，可逐首选择、切换，独立调整配乐与音效音量。配乐默认关闭；音效在首次主动操作后解锁。切换到后台时停止发声，偏好保存在当前浏览器。

专辑《汴京六景》包含六首不少于两分钟的原创作品，分别配合三卷场景。旋律按引子、主题、变奏、对比段、再现和尾声编写，使用琴、箫、筝、琵琶、笙的合成音色意象，并非真实乐器录音或宋代古谱复原。制作不使用外部录音采样。

七种音效对应点选、发现、提示、开页、收页、换卷和全卷完成。画卷拖动、鼠标悬停和连续缩放不叠加提示声。

原创乐谱保存在 `scripts/scores/`，可通过 `node scripts/compose-score-a.mjs` 和 `node scripts/compose-score-b.mjs` 重新生成。离线制作需要 Python 与 NumPy、FFmpeg，网页运行无需安装这些工具：

```sh
node scripts/render-sfx.mjs
python scripts/render-music.py --out /绝对路径/music-masters
node scripts/encode-music.mjs --ffmpeg /绝对路径/ffmpeg --masters /绝对路径/music-masters
```

最终配乐为 48 kHz 双声道、192 kbps MP3，音效为 48 kHz 双声道、24 bit WAV。成品清单记录实际时长、响度、峰值和 SHA256；制作母带放在仓库外，不进入网页目录。客观检查不替代实际设备听审。

## 资料与图像

主画卷使用用户提供的图像，物件点位经局部核对。斗笠、器皿等细节不作材质或窑口鉴定。

### 高清画卷

主画卷直接加载用户提供的原始 JPG：**38414 × 1800，18,637,705 字节，约 18.6 MB**。文件不切片、不重新编码、不降采样；无需图片生成或编码工具链。

“画卷长览”提供原图下载，缩放控件提供 `1:1` 原图像素查看；常规的 `100%` 仍表示适配当前画卷高度。小地图与全览缩略图仅用于导航，不用于主图细节显示。

源文件本身为 JPG，已有原先的编码压缩；这里保留的是源文件本身，不能称为原 JPG 本来无损。

青瓷配图：龍泉窯 青瓷蓮瓣紋碗，國立故宮博物院，臺北，CC BY 4.0。该器物为南宋十三世纪藏品，用作延伸鉴赏，并非画中同一器物。详见 https://digitalarchive.npm.gov.tw/Collection/Detail/23?dep=U 。

字体优先使用系统宋体；在线时可加载 Noto Serif SC，字体不可用不影响游玩。

## 发布

网页由 GitHub Pages 托管，部署目录为 `dist/`。推送 `main` 上的网页或工作流变更后，GitHub Actions 会检查脚本、上传网页并部署；也可在 Actions 页面手动运行“部署汴京寻物”。

部署检查应用与音频脚本的 JavaScript 语法，并执行 `node --test tests/audio.test.mjs`，直接上传成品资源；发布时不转换图片或重新合成音乐。

所有本地资源均使用相对路径，兼容 GitHub Pages 的仓库子路径。没有构建步骤，也不需要 npm 或 Jekyll。初次配置仓库时，Pages 的构建来源需要设为 GitHub Actions。
