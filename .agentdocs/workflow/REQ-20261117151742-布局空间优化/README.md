## 本轮范围与验收

页眉的“汴京寻物”下方显示“入一幅画，寻一件物”。画卷上方左侧显示画作署名与“宋”印，右侧显示“——循着小物，走进大宋日常。”。两处文字字号一致，与页脚共享行高。页眉到画卷上沿的介绍区与页脚等高，文案在介绍区内垂直居中。寻物笺继续贴在画卷左侧，宽度按画卷可见高度的三分之一计算。图标缩小，清单取消分割线及横向滚动。窗口高度为 353 px 时，两列三行可同时显示六件物品。底栏的画卷预览沿用基线高度，保持原卷比例并水平居中。页眉、介绍、画卷、操作栏和页脚均在同一视口内，画卷填满剩余高度。

桌面预览轨道高 39 px，窄屏高 32 px。窄屏把章节、长览入口和小地图分成两行。可见宽度不足时，居中的小地图裁切超出的部分，拖红框到可见边缘可以继续浏览。矮屏中寻物笺的物件区可以单独滚动。

界面显示的阿拉伯数字与缩放栏的 `1:1` 使用同一套字体。
