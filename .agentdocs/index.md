## 关键记忆

- 项目是无需构建的原生静态网页，`dist/` 保存可部署页面；不为预览引入框架或依赖。
- 音频控制器、界面、实际清单分置于 `audio.js`、`audio-ui.js`、`audio-catalog.js`。配乐为按需 MP3，音效为按需 WAV；完整声音体验需 HTTP，制作工具不参与网页运行。合成音色不能描述为真实录音。
- 主画卷直接加载 `qingming-original.jpg`，原图与世界坐标均为 `38414 × 1800`；源文件 18,637,705 字节。文件不切片、不重新编码、不降采样，不能将原 JPG 本身描述为无损。
- 现有约 18.6 MB 原 JPG 不需要分块和额外编码工具链；旧 21 片无损 WebP 合计约 92.4 MB，已移除当前部署产物与调度逻辑，Git 历史保留。小地图缩略图只负责导航。
- 互动点位必须与原画对应；缩放、拖拽、提示与命中使用同一套原图坐标，不再按半尺寸换算。
- 当前三卷分别为六、四、四处寻物点；货船在两卷出现，因此十四处进度对应十三种可寻得物件。百科另含虹桥、柳树、街铺、编篮，共十七条。
- 原图未能确认折扇，首卷改用可见的圆伞；“纸伞”属于器物理解参照，不宣称画面能够鉴定伞面材质。
- `assets/celadon.jpg` 为台北故宫南宋十三世纪龙泉窑青瓷莲瓣纹碗的官方参照图片（CC BY 4.0）；它不是画中同一件器物。
- 进度只保存在当前浏览器；存储不可用时应保持基本游玩能力。
- 恢复存档时只接受当前关卡白名单中的布尔发现记录；切关需取消延迟百科回调。画卷使用 `overflow:clip` 并在键盘聚焦热点时定位，防止内部滚动造成点位错位。
- GitHub Pages 使用 `workflow` 发布类型；`.github/workflows/pages.yml` 只部署 `dist/`，仅文档更新不重复触发网页部署。原 JPG 直载版本的部署提交与验证结果见最新 workflow；此前切片版本部署提交为 `00a8cb0a1cc7b71ffced45a9cabb21a8ad29c1ba`。
- 常规 Git HTTPS 传输被网络重置时，本次通过 `gh api` 精确同步 Git Database 对象并校验 SHA，保留原历史；同步辅助脚本仅放在工作区 `outputs/`，不进入仓库，也不保存凭据。
- Sites 的项目标识以 `.openai/hosting.json` 为准，不为同一项目重复创建站点。
