## 范围与验收

- 寻物条、图鉴分类、画卷长览和桌面小地图在相应一侧有隐藏内容时显示阴影。起点只显示右侧，末端只显示左侧，中间可同时显示两侧。
- 六类原生弹窗按实际可滚动方向显示边缘阴影。纵向溢出时用上下阴影。宽度足够、内容收起或弹窗关闭后不保留多余提示。
- 阴影采用以边缘中线为中心的椭圆渐变，沿边缘向两端淡出。寻物笺的阴影沿边缘铺开，只向内伸入约 5px，呈现微弧。
- 保持寻物条横滑、图鉴筛选、长览点击定位、桌面预览红框续拖与弹窗操作。主画卷继续通过画卷手势变换，沿用原图资源和坐标体系。
- 本地 Chrome 的专项阴影检查及 16 种视口回归通过，实体手机和其他浏览器待测。
