# 六首原创配乐与交互音效

## 背景与目标

- 会话：会话-33起；会话-36确认改用本地原创合成。
- 用户要求六首适合画卷寻物的高质量背景音乐，每首不少于两分钟，并为游戏动作制作恰当的音效。
- 外部音乐服务未连接；用户选择本地作曲、合成和混音路线。最终交付真实音频成品与游戏接入，不能以提示词或空曲目占位替代。
- 基础分支为 `main`，与上一轮相关修改一致，任务开始时工作区干净。

## 约束与原则

- 保持原 JPG 单图直载，不修改原图文件、画卷坐标或显示方式。
- 六首分别编写原创主题与段落发展，不用短片段循环填满时长；琴、箫等为合成意象，不称真实录音或古谱复原。
- 默认音乐关闭，用户主动开启；音效在用户操作后解锁。音量与开关独立保存。
- 不给悬停、拖拽、连续滚轮叠加音效；发现时自动弹百科不再叠加翻页声。
- 不引入网页运行依赖，制作工具只在离线阶段使用。

## 关键实现说明

- 六曲按三卷各两首配置，手动选择可覆盖当前章；切卷时只在当前曲不属于新章节时换曲。
- 配乐使用单个媒体元素，切曲前降低旧曲音量，防止快速切换留下重叠声部。
- 音效按需下载和解码；开/收页同属一类，迟到反馈丢弃，关闭音效立即取消正在播放的声音。
- 音效下载在八秒后中止，销毁控制器同时取消未完成下载；失败缓存删除后允许重试。
- 选曲意图在同一手势内提交，避免旧处理器等待后重新开启已暂停音乐；设置面板及试听不等待配乐网络就绪。独立审查发现这两处竞态，已修复并加整合回归。
- 离线母带为 48 kHz / 24 bit / stereo WAV；成品 MP3 使用双遍响度处理，目标 -20 LUFS、真峰值 -2 dBTP。
- 用户选择本地合成后，弃用未执行的外部音乐请求方案，不上传凭据或依赖外部音频服务。

## 关键风险

- 浏览器播放许可依赖用户手势，恢复偏好不能自动绕过限制。
- file 协议下 fetch 音效不可作为验收环境，需 HTTP 或 Pages。
- 物理模型与模态合成只能提供乐器意象；客观数值检查不能证明真实听感已通过。
- 长音频应按需加载，不在首屏预取整套配乐；母带不进入 Git。
