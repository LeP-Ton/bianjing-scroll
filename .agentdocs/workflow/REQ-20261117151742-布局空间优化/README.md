## 目标与验收

压缩顶部和页脚以扩大画卷舞台，使用紧凑顶栏，在底部控制台显示可收展的寻物笺。

1. 标题右侧显示“北宋 · 张择端《清明上河图》”及独立“宋”印。
2. 桌面左下章卷为两行，手机章节选择器为一行。寻物笺使用现有物品 SVG，完整支持六件与四件关卡。
3. 提示按钮无边框和下拉，手机只显示放大镜。桌面复位和全屏保留原图标，两者相邻且无分割线。
4. 画卷占屏面积增加，桌面参考视口高度目标超过 80%。寻物笺位于底栏，提示与键盘定位以画卷中心为准。
5. 保持拖拽、逐帧移动、平滑缩放、导航、提示命中、百科、存档、声音入口和长览正常；检查窄屏及横屏。
6. 原始 JPG 字节不变。与滚动边缘提示一同交付到新分支。
7. 底栏去掉内部竖向分割线，右侧文字与图标视觉尺寸接近。底部预览轨道按原卷 `38414 : 1800` 锁定比例，保留缩略图自身等比与准确定位。
8. 界面阿拉伯数字使用 `'Microsoft YaHei', sans-serif`。底栏移除 `1:1`，寻物条优先分配宽度。
9. 桌面底栏预览固定为 `25px` 高，宽度不足时拖红框碰到可见边缘，可继续露出隐藏画卷。松手或回到内部时停止续移。
10. 手机底栏第一行显示寻物笺和纯图标提示，第二行仅显示章节选择器。隐藏预览、加减缩放、复位和全屏，保留画卷拖动与双指缩放。

## 当前方案

- 页眉、游戏框使用实际视口高度分配，底部控制台参与布局。
- 宽屏底栏将章卷、寻物笺、预览和视图工具排在同一行。手机横竖屏均使用两行简化布局，物品条可横滑。
- 预览高度与比例固定，底栏的剩余宽度决定可见范围。空间充足时预览完整显示并靠近右侧减号。同排空间不足时，红框触边会联动预览与主画卷。保留预览点击定位和方向键。
- 保留加减缩放、定位和全屏。寻物笺标题可收展物品条，拖动画卷说明位于游玩帮助。
- 底栏按可见文字和图标协调组间距。定位和全屏保持相邻，延续原按钮点击范围。
- 图鉴保留“我的足迹”，手机页眉保留图鉴与长览入口。
- 运行继续使用原始 JPG 和原 SVG，设计稿的生成示意画面不作为网页资源。
